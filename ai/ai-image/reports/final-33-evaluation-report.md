# 이미지 AI 최종 33장 평가 보고서

## 1. 테스트 구성

| 구분 | 내용 |
| --- | --- |
| 이미지 정보 추출 | Qwen3-VL 8B Instruct |
| 이미지 프롬프트 | 최종 `analyze_image.txt` |
| 카테고리 분류 | qwen3:8b |
| 평가 데이터 | 기존 22장 + 신규 블라인드 11장 |
| 다중 할당 정책 | 2순위 45% 이상, 1순위와 점수 차이 10%p 이하 |
| 최대 카테고리 | 2개 |

이미지 모델은 카테고리를 선택하지 않고 제목·설명·태그·OCR·객체만 추출했다. 해당 추출 텍스트를 qwen3:8b에 전달해 카테고리 후보와 상대 적합도를 생성했다.

- 날씨 화면을 현재 카테고리 정의에 맞춰 생활·할 일로 정리
- 스포츠 관람과 장소 방문, 레퍼런스와 SNS처럼 두 의미가 모두 핵심인 경우 55/45 점수 사용

## 7. 실제 서비스 적용 판단

현재 구성은 **MVP 파일럿 적용은 가능하지만, 수백 장 규모의 운영 품질이 검증된 상태는 아니다.**

긍정 요소:

- 이미지 유형과 관계없이 구조화 출력 성공률 100%
- temperature 0, seed 42, JSON Schema를 사용해 출력 형식이 안정적
- 이미지 모델과 카테고리 모델의 역할이 분리되어 프롬프트와 모델을 독립적으로 교체 가능
- 33장 기준 1순위 정확도와 F1 90% 이상

제약 요소:

- 33장은 카테고리 11개와 다양한 실제 사용 패턴을 대표하기에 작음
- 현재 분류 가이드에 경기장·인테리어 등 시험 데이터와 가까운 예시가 포함되어 과적합 가능성이 있음
- 모델 점수는 실제 확률이 아니라 프롬프트에 영향을 받는 상대 점수이며 45% 임계값이 보정되지 않음
- 일반 사진은 사용자 저장 목적이 이미지에 나타나지 않아 기타와 다른 카테고리의 경계가 본질적으로 모호함
- `run_image_category_test.py`는 평가 실행기이며 운영용 작업 소비자·재시도·관측성 모듈은 아님

## 8. 권장 후속 검증

1. 현재 33장은 프롬프트 수정용 개발 세트로 고정하고 더 이상 이 데이터에 맞춰 규칙을 추가하지 않는다.
2. 팀원이 새로 제공한 미사용 이미지 100장 이상을 별도 검증 세트로 구성한다.
3. 카테고리별 최소 8~10장, 일반 개인 사진·스크린샷·문서·장소·상품·음식을 고르게 포함한다.
4. 1순위 정확도, 정답 포함률, 완전 일치율과 함께 카테고리별 혼동 행렬을 확인한다.
5. 사용자 수정 카테고리를 운영 정답으로 저장해 다중 할당 임계값을 재조정한다.

운영 후보 기준은 신규 검증 세트에서 1순위 정확도 85% 이상, 정답 포함률 90% 이상, JSON 성공률 99% 이상으로 두는 것이 현실적이다. 33장 개발 세트의 90.91%는 최종 성능 보장이 아니라 현재 구성의 개발 단계 지표로 사용한다.
