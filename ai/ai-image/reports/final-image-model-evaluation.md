# 이미지 모델 테스트 진행 결과

## 진행 내용

- 사용자 저장 이미지의 제목·설명·태그·주요 객체·OCR 텍스트 추출 기능 검증
- 이미지 모델의 최종 카테고리 직접 분류 제외
- 별도 텍스트 모델의 카테고리 분류에 필요한 이미지 정보 제공
- 네 개 후보 모델 대상 동일 이미지·동일 프롬프트 비교 테스트
- 최종 모델 선정 후 선정 모델만 프롬프트 개선 및 재평가

```text
이미지 저장
→ 이미지 모델의 정보 추출
→ 텍스트 모델의 최종 카테고리 분류
→ 데이터베이스 저장 및 검색 활용
```

## 비교 모델 및 선정 근거

| 구분 | 모델 | 선정 근거 | 주요 비교 항목 |
| --- | --- | --- | --- |
| 로컬 경량 모델 | Gemma 3 4B | 노트북에서 직접 실행 가능한 로컬 멀티모달 기준 모델 | 로컬 실행 가능성, 처리 시간, 정보 추출 품질 |
| 저비용 API 모델 | GPT-4o mini | 이미지 입력 지원 및 낮은 호출 비용 | 비용 대비 정확도, JSON 안정성, OCR 품질 |
| 고품질 API 모델 | GPT-4o | 이미지 분석 품질 비교를 위한 상위 기준 모델 | 태그·객체·OCR 추출 품질, 고성능 모델의 개선 폭 |
| 타사 API 모델 | Gemini 3.5 Flash | OpenAI 계열 이외의 멀티모달 비교 후보 | 공급자별 품질, 처리 속도, 응답 안정성 |

### Gemma 3 12B 최종 비교 제외

- RTX 4070 Laptop GPU 8GB 환경에서 모델 전체 적재 불가
- 4비트 양자화 및 CPU 오프로딩 적용 후 정상 결과 생성 실패
- 동일한 11장 테스트 결과 부재
- 정상 실행된 네 모델만 최종 정량 비교 대상으로 선정

## 테스트 구성

### 폴더 구조

```text
ai-image/
├─ datasets/
│  ├─ images/                 # 테스트 이미지 11장
│  └─ ground_truth.jsonl      # 이미지별 정답 태그 및 분류 근거
├─ prompts/
│  └─ analyze_image.txt       # 모델 공통 프롬프트
├─ providers/
│  ├─ base.py                 # 모델 연결 공통 규격
│  ├─ gemma.py                # 로컬 Gemma 연결
│  ├─ gms.py                  # GMS GPT 연결
│  └─ gemini_gms.py           # GMS Gemini 연결
├─ results/                   # 실행별 원본 JSONL 결과
├─ reports/                   # 비교 보고서 및 상세 CSV
├─ run_benchmark.py           # 공통 테스트 실행
├─ evaluate.py                # 평가 지표 계산
├─ report.py                  # 비교 보고서 자동 생성
└─ run_*.ps1                  # 모델별 실행 스크립트
```

### 실행 환경 및 방식

| 항목 | 구성 |
| --- | --- |
| 로컬 실행 환경 | Windows, Python 3.12, PyTorch, Transformers, CUDA |
| GPU | NVIDIA GeForce RTX 4070 Laptop GPU 8GB |
| 로컬 모델 최적화 | bitsandbytes 4비트 양자화 |
| API 호출 환경 | SSAFY GMS 프록시 및 `.env`의 `GMS_API_KEY` 사용 |
| 공통 입력 | 동일한 테스트 이미지 11장 및 동일 프롬프트 |
| 공통 출력 | 제목, 설명, 태그, OCR, 객체, 신뢰도 JSON |
| 생성 조건 | `temperature: 0.0` 적용 |
| 결과 저장 | 실행별 JSONL 원본 결과 저장 |
| 보고서 생성 | 모델 요약 CSV, 이미지별 상세 CSV, Markdown 자동 생성 |

## 2차 테스트: 선정 모델 프롬프트 개선

1차 비교에서 선정된 **GPT-4o mini만 대상**으로 프롬프트 개선 및 동일 11장 재실행

### 프롬프트 개선 내용

- 중심 대상·행동·배경·OCR·검색 단서 순서의 관찰 지침 추가
- 대상과 상황이 드러나는 구체적인 제목 생성 규칙 추가
- 활동·장소·문서 유형을 포함한 검색용 태그 규칙 추가
- 날짜·시간·금액·상호명·제품명 보존 규칙 추가
- 영수증 및 문서의 줄바꿈·숫자·기호 보존 규칙 추가
- 보이지 않는 위치·목적·인물 정보 추측 제한
- 파싱 가능한 JSON 형식 준수 규칙 강화
